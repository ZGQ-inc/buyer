# 拼多多买家订单数据导出工具

基于 **Playwright** 自动化仿真与多引擎数据捕获（SSR 首屏数据注入 + 网络 API 实时拦截 + DOM 解析）实现的拼多多买家全量数据导出工具。

## 功能特性

1. **会话持久化与登录引导**
   - 自动启动移动端仿真窗口，支持手机验证码登录。
   - 使用持久化 Profile (`pdd_profile/`) 模式，Cookie 与设备指纹自动保存，免去频繁重新登录。

2. **全部订单导出**
   - **多引擎全量捕获**：页面首屏服务端渲染（SSR）数据提取 + 自动平滑滚动网络 API 拦截，确保从最新订单到账号历史第一单 100% 完整抓取。
   - **实时增量落盘（防中断数据丢失）**：边导出边实时同步写入磁盘主文件，中途若意外中断或手动关闭，当前已导出的数据完好无损。
   - **全量字段覆盖**：订单编号、订单类型（普通/多多买菜）、商品名称、商品规格、单价(元)、数量、订单总金额(元)、订单状态、店铺名称、下单时间、商品购买链接。
   - **多格式输出**：Excel (`.xlsx`)、CSV (`.csv`)、JSON (`.json`)。

3. **全部收藏与关注导出**
   - **商品收藏**：全面支持在售商品以及**已售罄、已下架、失效商品**，记录商品状态（在售/已售罄/已下架/失效）、收藏价格、店铺名称、商品链接。
   - **店铺关注**：记录店铺名称、关注人数、在售商品数、店铺主页链接。
   - **多 Sheet 整合**：自动生成包含 `商品收藏` 与 `店铺关注` 两个工作表的汇总 Excel。

## 目录结构

```
project/
├── config.py             # 全局配置
├── utils.py              # 数据清洗、反爬绕过与格式化工具
├── login.py              # 交互式登录引导
├── export_orders.py      # 全部订单导出（实时增量）
├── export_favorites.py   # 全部收藏导出（含售罄商品与店铺关注）
├── main.py               # 控制台菜单
├── login.bat / run.bat   # Windows 快捷启动脚本
├── requirements.txt      # 依赖包
└── output/               # 数据导出目录
    ├── pdd_orders.xlsx   # 订单 Excel
    ├── pdd_orders.csv    # 订单 CSV
    ├── pdd_orders.json   # 订单 JSON
    └── pdd_favorites.xlsx# 收藏 Excel
```

## 安装依赖

```bash
pip install -r requirements.txt
playwright install chromium
```

## 快速使用

### 方式 1：控制台菜单（推荐）

```bash
python main.py
```
> Windows 用户亦可直接双击 `run.bat` 启动。

### 方式 2：分步运行

```bash
# 1. 登录拼多多买家账号
python login.py

# 2. 导出全部订单
python export_orders.py

# 3. 导出全部收藏
python export_favorites.py
```

## 已知问题

* **收藏（商品收藏 / 店铺关注）可能无法稳定抓取**：
  * **原因说明**：拼多多移动端网页版（H5 页面 `likes.html` 及 `psnl_mall_collection.html`）对收藏与关注接口采用了严格的风控与频控策略（接口容易返回 HTTP 429 `REFUSE` 或页面提示“系统繁忙/暂无收藏”），且部分账号的收藏数据被官方限制仅能在移动端 App 内加载，导致网页端无法稳定拉取全量收藏列表。
  * **当前状态**：**订单导出功能（含普通订单、多商品订单、多多买菜订单等全量历史）完全稳定可用**；收藏导出受平台网页端风控限制可能无法获取，后续若有可用绕过方案将持续更新。
